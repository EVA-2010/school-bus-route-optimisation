# School Bus Route Optimisation in Ludhiana

This project uses graph theory and Python to compare an existing school-bus route with an optimised route around Sarabha Nagar, Ludhiana.

## Methods

- Weighted graph modelling
- Haversine geographic distance
- Dijkstra’s shortest-path algorithm
- Nearest-neighbour route optimisation
- Python data analysis and visualisation

## How to Run

```bash
pip install -r requirements.txt
python bus_route_optimisation.py
```

## Results

The project compares the existing route with an optimised route and reports total distance, distance saved, and percentage improvement.

## Files

- `bus_route_optimisation.py`: Main Python program  
- `results/`: CSV results and research graphs  

## Limitations

Actual student addresses and school-specific route data were not used. Distances are estimated from geographic coordinates for a privacy-preserving case study.
